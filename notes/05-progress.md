## Instruction gaps remaining

`frchg`, `fschg`, `fsca`, `fsrra`, `fcnvsd`; 303 total). Both are left
`Unimplemented` on purpose: `div1`'s non-restoring step could not be validated
against a trusted division sequence, and the vector instructions need the
matrix-register model. A wrong oracle is worse than a loud gap.

## Loop

One port per file: `rust/lemans-verify/src/ports/p_<address>.rs`, with the
lookup table generated by `scripts/gen-registry.py`. A port is only recorded in
`notes/address-map.md` when `scripts/verify-function.sh` prints `ok` and writes
`notes/verifications/<address>.json` with `"result": "pass"`.

Parallel porting uses isolated workspaces (`scripts/agent-workspace.sh`), so two
agents never share a target dir or a registry file. `scripts/collect-batch.py`
refuses to overwrite a differing port, and `scripts/verify-ports.sh` re-runs
every address canonically after a merge.

Batches 41-43 landed 30 ports. The recurring failure classes remain
caller-visible register residue and allocator fixtures: a freed pointer is the
block start, so `[p-8]` must point at the arena head (`0x8c220000`), `[p-4]`
holds the size (`0x40`) and `[p]` the next-chunk word (`0x1000`); with those
seeded, four-pointer release chains verify in one shot.
